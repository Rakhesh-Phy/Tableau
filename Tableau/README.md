# NYC TCL Green Trip Data Tableau Desktop

IN this project, we created detailed analysis of trip demand and revenue using **Tableau Desktop**.

The dataset was sourced from this link:[TLC Trip Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

Outomes of the Project:

* North Harlem had the most number of trips in single day.
* Overall, the **demand was higher in the evenings**.
* The **zone with most demand is not associated with maximum average revenue**.
